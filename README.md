
Health Management Application (Desktop) 
--- 
## Overview
This project is a desktop-based Health Management Application developed by a team of 3 members. The system is designed to manage and track users' health-related information, ensuring data accuracy and usability.

In this project, I was mainly responsible for **software testing**, focusing on validating system functionality, ensuring data consistency, and improving overall user experience.


## Objectives
- Ensure system functionality works as expected  
- Validate data accuracy and consistency  
- Identify and report defects from a user perspective  
- Improve system quality through structured testing  



## Team Responsibilities
- Designed and executed **119 test cases** based on predefined test documents  
- Performed **manual testing** for desktop application features  
- Conducted **functional testing** and validated system workflows  
- Reported bugs with clear reproduction steps and expected vs actual results  
- Performed **cross-testing** on teammates’ features to ensure overall system quality  



## Testing Approach
- Test Case Design based on requirements  
- Functional Testing  
- Exploratory Testing  
- Data Validation  



## Tools & Technologies
- Testing: Manual Testing  
- Documentation: Microsoft Excel, Microsoft Word  
- Version Control: Git  
- Platform: Desktop Application  



## Key Achievements
- Successfully executed **119 test cases**
